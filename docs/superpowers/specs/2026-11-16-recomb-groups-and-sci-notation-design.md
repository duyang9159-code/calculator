# 同源重组多组计算 + 悬液总细胞量科学计数法 设计文档

日期:2026-11-16
影响文件:`index.html`(单文件应用,F:\Projects\calculator)

## 背景

1. 多片段同源重组模块目前只能计算一个实验组;实际实验需要一次并行计算多组。
2. 悬液总细胞量以 `toFixed(2) ×10⁶ 个` 显示,当细胞量只有几千时(如 0.005 ×10⁶)显示为 0.01,严重失真。

## 需求 1:多片段同源重组多组支持(最多 5 组)

### 交互

- 顶部输入区改为两个全局选择器:
  - 插入片段数量:1–5 个(全组共用,沿用现有 `fragment_count`)
  - 实验组数:1–5 组(新增 `hr_group_count`),**默认 1 组**
- 原顶部"载体长度 / 载体浓度 / 载体加入质量"三个输入框移除,移入每组卡片。
- 每组一张卡片"实验组 g",内容:
  - 载体长度(bp)、载体浓度(ng/μL)、载体加入质量(ng)
  - 片段 1..n 的长度(bp)、浓度(ng/μL)、摩尔比(片段:载体)
- 组 2–5 的默认值复制组 1 的默认值(片段默认值沿用现有数组:[2000,1500,800,600,400] bp / [500,400,300,250,200] ng/μL / 摩尔比 2)。
- 切换组数 / 片段数时保留已填值(保存-重建模式,同转染模块)。

### 结果展示

转置表格:行 = 载体体积、片段 1..n;列 = 组 1..5。片段单元格同时显示体积和质量,格式 `0.80 μL (40.0 ng)`;载体行只显示体积,格式 `0.10 μL`(体积 2 位小数,质量 1 位小数,与现有一致)。复用 `.table-wrapper table.lab-table` 样式,窄屏横向滚动。

### 计算逻辑(不变)

- 载体体积 (μL) = 载体质量 / 载体浓度
- 片段质量 (ng) = (载体质量 / 载体长度) × 摩尔比 × 片段长度
- 片段体积 (μL) = 片段质量 / 片段浓度

### 历史记录

每组一条:`组1: 载体 1.00 μL | 片段1 0.80 μL | …`;输入摘要含"片段数""组数"。

### 实现要点

- 状态变量 `currentHrGroupCount`(默认 1)。
- 元素 ID 命名:`hr_group_count`;每组 `hrg${g}_vector_bp` / `hrg${g}_vector_conc` / `hrg${g}_vector_mass`;每片段 `hrg${g}_frag${i}_bp` / `_conc` / `_ratio`(替换现有 `hr_vector_*`、`frag${i}_*`)。
- `renderFragments()` 扩展为"组 × 片段"渲染;`updateMultiFragment()` 逐组计算并生成转置表格。
- 现有片段保存-重建逻辑扩展到组维度(保存 g=1..5、i=1..5 的所有值)。

## 需求 2:悬液总细胞量自适应科学计数法

### 规则

- 复用现有 `toSciSup(num)`(第 1387 行):0 → `0`;否则尾数 1–9.99(2 位小数)、指数 `floor(log10)`,HTML 显示 `m × 10<sup>e</sup>`。
- 新增纯文本版 `toSciText(num)`(格式 `5.00x10^3`),用于历史记录。
- "悬液总细胞量"显示改为:`toSciSup(总细胞量 × 10⁶)` + 单位"个"。即先把 ×10⁶ 单位下的数值换算为实际细胞个数,再做科学计数法。
- 示例:5000 个 → `5.00 × 10³ 个`;1,230,000 个 → `1.23 × 10⁶ 个`;0 → `0 个`。
- 历史"总量"字段用 `toSciText(总细胞量 × 10⁶)`。
- "当前细胞浓度"**保持现状**(×10⁶ 个/mL,toFixed(3)),不在本次范围内。

## 边界与错误处理

- 任一输入为空/非法时沿用现有 `parseFloat(...) || 默认值` 策略,计算不抛错。
- 总细胞量为 0 时显示 `0 个`(toSciSup 已处理)。
- 除数为 0 时沿用现有防护(默认 1)。

## 验证

单 HTML 文件,无自动化测试框架,采用手动验证:

1. 同源重组:组数 1→3→5 切换,值保留;片段数切换,值保留;表格数值手算对照(载体体积、片段质量/体积)。
2. 悬液总细胞量:构造 5000 个、123 万个、0 三种场景,核对显示与历史记录文本。
3. 回归:细胞计数模块三种模式(浓度调整/细胞获取/已知浓度)结果不受影响;微信验证文件不受影响(只改 index.html)。
