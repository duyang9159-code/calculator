## 需求 2:TCID50(Reed-Muench 法)

### 输入

即需求 1 的 12 排病变孔数 + 复孔数 + 接种体积。

### 算法

1. 每排病变率 p_r = c_r / n(n = 复孔数,c_r = 该排病变孔数)。
2. 从**最稀排**(第 12 排)向浓端累计:第 r 排的累计阳性数 = 第 r..12 排 c 之和;累计阴性数 = 第 1..r−1 排 (n − c) 之和。第 r 排累计病变率 P_r = 累计阳性 / (累计阳性 + 累计阴性)。
3. 在稀释序列上找到**累计病变率 ≥ 50% 的最稀排**(上排,记指数 e_上、P_上),及其更稀一档的下一排(下排,记指数 e_下 = e_上 − 1、P_下 < 50%)。
4. 比例距离 PD = (P_上 − 50) / (P_上 − P_下)。
5. 终点稀释指数 e = e_上 − PD(以 10 为底的对数坐标;e_上即上排"10 的指数",排 r 的指数为 1−r)。
6. TCID50/mL = 10^(−e) × 1000 / 接种体积(μL)。

### 结果展示(三个数)

- `log₁₀(TCID50/mL)`(保留 2 位小数)
- `TCID50/mL 线性值`(用 `toSciSup` 显示)
- 终点稀释度(如 `10⁻⁶·⁵ 稀释`)

### 边界处理

- 12 排病变孔数全为 0 → 结果显示"未检出病变,建议提高病毒浓度或减少稀释"。
- 所有有病变的排累计病变率均 ≥ 50%(最稀排也有病变) → 显示"终点超出最稀排,建议增加稀释梯度"。
- 无上排或无下排导致无法插值时,不输出数值,只显示说明文字。
- 复孔数为 0 或接种体积为 0 时,TCID50 不计算(显示提示)。
